# Branchline Verdict identity brief

- Mechanism signature: validators answer an ordered path through an owner-defined binary decision tree; the contract derives the leaf and rejects invented, skipped, cyclic, or post-leaf steps.
- Product metaphor: a railway signal map where one evidence record lights a single route from root to terminal.
- Narrative voice: procedural and spatial. Short instructions use route verbs: place, connect, walk, arrive.
- Visual grammar: pale drafting paper, cobalt track lines, vermilion active route, circular question junctions, rectangular terminal stations.
- Interaction grammar: compose a tree visually, file one case in a side ticket, then watch the authoritative path illuminate.
- Documentation style: route legend first, invariants second, reproducible trip last.
- Evidence story: source digest, exact question indexes, Boolean answers, derived terminal, and finalized transaction remain attributable to one case.
