# Mechanism and interface difference matrix

| Comparison | Branchline Verdict | Why it is not a rename |
| --- | --- | --- |
| Claim Census / Recall Verdict | Those contracts classify a claim directly from sources | This contract records an ordered sequence of Boolean findings and derives the only reachable leaf deterministically |
| Mandate Router / Mandate Fuse | Those contracts authorize a request against grants or a frozen policy | This contract has no principal, delegate, permission, expiry, or consumable authorization |
| Repair Cascade | That contract verifies nodes in a repair dependency graph | This contract navigates exactly one mutually exclusive path in a frozen decision tree |
| Reciprocal Draft | That contract computes a compatibility graph and one-to-one pairs | This contract never matches participants or constructs edges dynamically |

## Visible interaction separation

Branchline uses a zoomable-style railway tree, root-to-leaf illumination, and a compact case ticket. It does not use a hero plus repeated form cards, mirrored input columns, a dashboard grid, or raw argument rows.
